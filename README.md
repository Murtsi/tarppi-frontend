# Tärppi — Kide-käyttöliittymän esittely

Kevyt, responsiivinen esittelysivu Tärpille. Mukana on kuvitteellisia tapahtumaesimerkkejä, käyttöohje ja linkki varsinaiseen palveluun.

**[Avaa Tärppi →](https://www.tarppi.site/)**

## Sisältö

- `index.html` — sivun rakenne ja esimerkkitapahtumat
- `style.css` — ulkoasu ja mobiilinäkymä
- `package.json` — kehitys- ja build-komennot

## Kehitys

Node.js 24:

```sh
npm ci
npm run dev
```

Tuotantoversio: `npm run build`. Esikatselu: `npm run preview`.

Tämä repo on visuaalinen esittely. Esimerkkitapahtumat eivät ole oikeita myyntejä, eikä sivu varaa lippuja tai muodosta yhteyttä palveluihin.
